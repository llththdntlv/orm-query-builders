Решения для баз данных в языке Python

Python знаменит своими мощными фреймворками для веб-разработки, каждый из которых включает продвинутые инструменты маппинга данных.

SQLAlchemy

Промышленный стандарт для Python-приложений. Это гибкий инструмент, совмещающий в себе и мощный Query Builder, и Data Mapper ORM. Позволяет опускаться до уровня сырого SQL в любой момент.

Django ORM

Встроенная ORM-система монолитного фреймворка Django. Базируется на паттерне Active Record. Славится своей мощной системой автоматической генерации файлов миграций.
