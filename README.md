# Учебный проект: Использование CSS фреймворков

### Тема: ORM и Query Builders
Справочный веб-ресурс, созданный с целью изучения архитектурных шаблонов взаимодействия с базами данных (ORM, Query Builders, чистый SQL).

### Технологический стек:
* **HTML5:** Семантическая разметка страниц.
* **CSS3:** Кастомные стили (темная IT-тема, шрифты, адаптивность плеера).
* **CSS-фреймворк:** Picnic CSS (v7).
* **JavaScript:** Нативный код для мобильной навигации.
