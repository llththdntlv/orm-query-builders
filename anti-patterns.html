Популярные ошибки и антипаттерны использования ORM

Абстракции могут играть злую шутку с неопытными разработчиками. Рассмотрим критическую проблему систем объектно-реляционного отображения.

Проблема запросов N+1

Этот антипаттерн возникает, когда приложение выполняет один запрос для получения родительских записей, а затем совершает по одному отдельному SQL-запросу для получения связанных данных каждой строки в цикле.

В результате вместо 1 или 2 оптимизированных запросов с оператором JOIN, база данных выполняет сотни мелких транзакций, намертво блокируя работу веб-сервера.

Важно

Всегда используйте логирование запросов (SQL Logging) на этапе локальной разработки.
